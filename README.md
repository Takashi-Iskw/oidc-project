\# プロジェクトについて



Keycloakを用いたOpenID Connect（OIDC）ログインができる、シンプルなバグ管理アプリです。



\## 本プロジェクトで実装していること



\- Keycloak を用いた OIDC ログイン

\- PKCE（S256）の対応

\- 権限(scope)ごとに利用できる機能を分離

&#x20; - admin: プロジェクト作成など

&#x20; - user: バグのCRUD操作など



\## 利用技術



\- Java

\- Spring Boot

\- Spring Security

\- OAuth2 Client

\- Maven

\- Keycloak
